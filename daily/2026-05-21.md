#### Topic | 主题: Handbook Prompt 章节 + Prompt Engineering 实验

**Key Concepts | 关键概念**:
1、**Prompt 是软约束，不是安全边界。真正的边界必须由代码、权限、校验和审计来承担。**
2、**instruction**
任务目标、可用输入、禁止行为、输出格式和失败格式
3、**few shot**
示例不是一次写完的素材，而是要跟 eval 一起维护的测试资产
4、**structured output**
结构化输出不是为了好看，而是为了让后续代码能检查、拒绝、记录和回归测试。
5、**prompt injection 攻击**
把外部内容标记为不可信数据
工具调用前做参数校验
敏感动作强制走 allowlist 和 human approval
不把密钥、主权限和不可撤销动作交给模型
6、ai*web3中的位置
Prompt 处在用户目标和模型行为之间。prompt不该独自承担安全风险：
Prompt 定义任务和输出格式。
Context 提供可信数据和来源边界。
Model 生成解释或候选动作。
Code 校验 schema 和业务规则。
Guard / simulation 检查链上影响。
Human check 确认高风险动作。
