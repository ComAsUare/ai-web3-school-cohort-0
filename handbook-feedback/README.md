## 反馈类型

- **Typo**: 错别字、格式错误
- **Unclear**: 概念解释不清、缺少示例
- **Outdated**: 信息过时、链接失效
- **Structure**: 结构建议、章节组织
- **Missing**: 缺少关键内容

## 提交流程

1. 在 `handbook-feedback/` 下创建 `YYYY-MM-DD-brief-title.md`
2. 包含：页面链接、问题描述、建议改法
3. 学习 Agent 会汇总并生成 Handbook PR
4. 提交至 https://github.com/lxdao-official/aiweb3school
